What is a DOB?
⛓️

Fully on-chain

Content lives inside the CKB cell — no IPFS, no S3, no URLs that can break.

💎

Intrinsic value

Backed by real CKB. Burn the DOB any time to reclaim the storage deposit.

🔒

🌐
